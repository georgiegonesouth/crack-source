# PT Notes — Cheatsheet Web App

A local pentesting cheatsheet browser. No build step, no framework — plain HTML/CSS/JS.

## Running locally

**Option A — Python (built-in, recommended):**
```bash
cd /path/to/cheatsheet_webiste
python3 -m http.server 8080
# Open: http://localhost:8080
```

**Option B — any static server:**
```bash
npx serve .          # Node
ruby -run -e httpd . # Ruby
caddy file-server    # Caddy
```

**Option C — VS Code Live Server** or any IDE "Open with Live Server" extension.

> Direct `file://` open **will not work** — browsers block `fetch()` for local files.
> You must serve it via HTTP.

---

## Regenerating the nav manifest

The sidebar is built from `manifest.json`, which is generated by scanning `CHEATSHEETS/`.

**Whenever you add, rename, or remove a file:**
```bash
python3 generate_manifest.py
```

That's it. Refresh the browser tab and the new file appears in the sidebar.

The script picks up any `.md` or `.pdf` file inside `CHEATSHEETS/`. Empty folders are included
(they show in the nav but have no children). Filenames starting with `.` are ignored.

## Placeholder token convention

All new cheatsheets you write should use these exact tokens as placeholders inside commands:

| Token | Meaning |
|---|---|
| `<TARGET_IP>` | Target machine IP (or FQDN) |
| `<PORT>` | Target service port |
| `<LHOST>` | Your listener / VPN IP |
| `<LPORT>` | Your listener port |

**Example:**
````markdown
## Connect

    nc -nv <TARGET_IP> <PORT>

## Catch shell

    nc -lvnp <LPORT>
````

When you type your actual values into the input bar at the top of the app, every occurrence
of these tokens in code blocks is substituted live. Unfilled tokens are highlighted in red
so you notice them before copy-pasting.

The **Copy** button on every code block copies the fully-substituted text.

## What was standardised (existing files)

The following placeholder variants were found and replaced:

| Old token | Replaced with | Files affected |
|---|---|---|
| `<IP>` | `<TARGET_IP>` | netcat, nmap, tcpdump, dns, ftp, imap_pop3, mysql, nfs, oracle_tns, smb, smtp, snmp |
| `<FQDN/IP>` | `<TARGET_IP>` | mssql |
| `<TARGET>` | `<TARGET_IP>` | concepts (used in domain/crt.sh grep commands) |
| `<target>` | `<TARGET_IP>` | ftp (wget command) |

**Not changed (intentionally):**
- `<SCRIPT>` in `reverse_shells.md` — PHP/code body placeholder, not a host/port
- `<PS>` in `mssql.md` — PowerShell command body placeholder
- `<ID>` in `imap_pop3.md` — IMAP message ID, not a network target
- `10.10.10.X` in `approach.md` — hardcoded example address, not a substitution token

## Structure

```
cheatsheet_webiste/
├── index.html            ← app entry point
├── style.css             ← dark theme styles
├── app.js                ← all app logic
├── manifest.json         ← auto-generated nav manifest (re-run script after file changes)
├── generate_manifest.py  ← manifest generator
└── CHEATSHEETS/          ← your content (do not restructure)
    ├── KNOWLEDGE_BASES/
    ├── OS/
    └── TARGET_INTERACTION/
```
